## Executive Summary
This is the consolidated technical reference underpinning SVMH's future product pages, buyer guides, and RFQ logic. It anchors every crane type to the governing **Indian Standards** (IS 807 structural, IS 3177 EOT design, IS 13834 classification, IS 4137 heavy/steelwork) cross-referenced to **FEM/ISO M-classes** and **CMAA A–F**. The single most important buyer-facing concept is **duty class** — the variable competitors most often let buyers under-specify, causing premature failure. SVMH's knowledge advantage is publishing this India-standards content clearly, which no competitor consistently does.

## 1. Standards anchor
| Standard | Scope |
|---|---|
| **IS 3177:1999** | Code of practice for EOT & gantry cranes (non-steelwork); Annexure-A = buyer info set |
| **IS 807:2006** | Design, erection & testing (structural); girder deflection ≤ 1/750 span (>12 m) / 1/600 (<12 m) |
| **IS 13834 (Pt 1 & 5):1994** | Crane classification (general / overhead & portal) |
| **IS 4137** | Heavy-duty/steelwork EOT (ladle) — confirm current revision |
| **FEM 9.511 / ISO** | Duty groups M3–M8 · **CMAA 70/74** classes A–F · **HMI/ASME** hoist H1–H5 |

**Duty-class cross-reference:** M3≈CMAA A/B (standby/light) → M5≈C/D (moderate–heavy) → M6≈D/E → M7≈E (severe) → M8≈F (continuous severe, ladle). Exact class = load-cycle calculation, not a lookup.

**Wire-rope safety factors (IS 3177 cl. 8.3.2):** 4.62 / 5.25 / 5.6 / 5.95 for M3/M5/M7/M8. **Molten metal: min 8:1**, load ≤12.5% of rope breaking strength.

## 3. Buying considerations by type (headline)
- **Single vs double girder:** single for ≤15 T / ≤18–20 m span / moderate duty; double above, or when cabin/aux-hoist/high hook needed. Single ~30–45% cheaper at equal capacity.
- **Gantry:** choose when no building runway exists; outdoor needs wind/seismic + corrosion protection.
- **Ladle/foundry:** governed by IS 4137 + IS 807; safety redundancy (8:1 rope, dual brakes) non-negotiable — a genuine engineering moat.
- **VFD vs contactor:** specify VFD for M5+ (smooth control, longer fatigue life).

## 4. Safety & compliance essentials
- Load-suspension parts 5:1 (IS 3177 cl. 7.4.2); brakes per cl. 8.12; earthing per IS 3043; welding per ASME Sec IX; motors S4 crane duty; festoon EPR per IS 9968.
- **Factory Acceptance / commissioning test:** no-load run → 100% SWL operational → **125% SWL static overload**, witnessed + certified.
- **Operator training** per IS 13367.
- **Certifications buyers expect:** IS 807 + IS 3177 baseline, ISO 9001 QMS, + DGMS (mining) / CE (export/MNC). *(See `10_Certifications/`.)*

## 5. Maintenance cadence
- M3–M5: quarterly formal inspection + daily pre-shift checks. M6–M8: monthly. Focus: hoist rope inspection/replacement, brake clearance, limit-switch test, running-gear lubrication, weld-toe crack inspection, girder deflection.
- Common failures: rope wear/kink, brake drag/overheat, wheel/rail misalignment, limit-switch failure, contactor burn-out (→ VFD/stabilizer fix).
