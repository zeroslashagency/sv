## 🎨 RESPONSIVE BEHAVIOR

### Desktop (1200px+)
- Multi-column layouts stay side-by-side
- Hero knockout typography at full size
- Navigation horizontal

### Tablet (768px – 1199px)
- 3-column grids become 2-column
- Side-by-side sections remain, slightly narrower
- Hero typography scales down

### Mobile (<768px)
- All multi-column layouts stack vertically
- Navigation becomes hamburger menu
- Hero knockout typography much smaller or simplified
- Cards/tiles stack in single column

## ✏️ HOW TO EDIT THIS LAYOUT

1. **Delete a section**: Remove the entire section block (including the ASCII box)
2. **Reorder sections**: Cut and paste section blocks in your preferred order
3. **Change column count**: Edit the number of boxes in grid/triptych sections
4. **Swap image/text sides**: Swap the position of text and image columns
5. **Add new sections**: Duplicate an existing section block and modify the content

### Example Edit:
```diff
- Section 10/13 — Industries Grid (6 tiles)
+ Section 10/13 — Industries Grid (4 tiles only)
```
