Capability

Design, fabrication and testing under one roof

01

Duty class calculated, not guessed

IS 3177 derives class from lifts per day and average load. An M3 machine on an M5 job cracks inside four years — the replacement gets bought with the bay stopped.

02

Girder analysed to IS 807 deflection limits

L/750 above 12 m span, L/600 below. Sections are not picked from a supplier chart — the deflection check is submitted with the technical offer.

03

Factory acceptance test before dispatch

100% SWL operational, then 125% static overload. Witnessed by the buyer or their consulting engineer, and certified. Never skipped, never paper-only.
